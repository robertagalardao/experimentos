Qual a função do atributo alt?

O atributo alt serve para descrever o conteúdo de uma imagem em formato de texto na tag .

Ele é importante para acessibilidade, pois permite que pessoas com deficiência visual compreendam o conteúdo da imagem através de leitores de tela.
Além disso, o atributo alt também é útil para SEO (Search Engine Optimization), ajudando os motores de busca a entenderem o conteúdo da imagem.
